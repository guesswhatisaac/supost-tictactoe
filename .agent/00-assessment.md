## 3. Functional requirements (recommended baseline)

The written instructions do not enumerate exact behavior. This baseline is subject
to verification against the Loom video.

- [ ] Display a 3x3 Tic-Tac-Toe board
- [ ] Allow two players to alternate between X and O
- [ ] Prevent moves on already occupied cells
- [ ] Detect winning combinations across rows, columns, and diagonals
- [ ] Detect a draw when the board is full without a winner
- [ ] Display the current player's turn and game result
- [ ] Prevent additional moves after the game ends
- [ ] Provide a restart or reset game button
